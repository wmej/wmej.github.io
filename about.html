关于

从小我就喜欢电子产品和数码。高中那会儿天天想着有个自己的网站，在 GitHub 上折腾过一阵，没做出什么。后来就搁下了。

再捡起来是 AI 出来以后。我用 Claude Code 写小程序，管它叫 cc，这时候才算真的做出东西。

到现在做过几样。一个叫「剑开星河」的个人主页，已经上线，没有后端；一个是给两个人用的记录小程序，在别人开源的项目上改的；还写过一个浏览器书签插件。

都不算厉害。可每一样都是我自己想要、又没人替我做的。
